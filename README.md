## Inference & API Platforms

- [Anthropic](https://www.anthropic.com) - AI research company behind Claude, offering the Anthropic API for large language models.
- [OpenAI](https://openai.com) - Provider of GPT models, embeddings, and the OpenAI API platform.
- [Groq](https://groq.com) - Ultra-fast inference platform running open models on LPU hardware.
- [Mistral AI](https://mistral.ai) - European AI lab offering open-weight and commercial LLM APIs.
- [Cerebras](https://www.cerebras.ai) - High-throughput inference service running open models on the Wafer-Scale Engine.
- [DeepSeek](https://www.deepseek.com) - Open-weight reasoning models served through a low-cost API platform.
- [Together AI](https://www.together.ai) - Cloud platform for training, fine-tuning, and running open models.
- [Fireworks AI](https://fireworks.ai) - Fast, production-grade inference for open-source models.
- [Replicate](https://replicate.ai) - Run open-source models with a simple HTTP API.
- [Fal.ai](https://fal.ai) - Fast inference platform optimized for production AI workloads.
- [Modal](https://modal.com) - Serverless cloud platform for running AI and GPU workloads.
- [Baseten](https://www.baseten.co) - Infrastructure for deploying and scaling ML models as APIs.
- [Lepton AI](https://www.lepton.ai) - Cloud platform for running AI applications and fine-tuned models.
- [Hugging Face](https://huggingface.co) - Platform for hosting, sharing, and deploying ML models and datasets.

## Model Hosting & Local Inference

- [Ollama](https://ollama.com) - Run open-source LLMs locally with a simple CLI and API.
- [vLLM](https://github.com/vllm-project/vllm) - High-throughput inference and serving engine for LLMs.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) - C/C++ inference for LLMs optimized for CPU and GPU.
- [SGLang](https://github.com/sgl-project/sglang) - Fast serving framework for LLMs and multi-modal models.
- [LM Studio](https://lmstudio.ai) - Desktop app for discovering, downloading, and running local LLMs.

## Embeddings & Vector Databases

- [Pinecone](https://www.pinecone.io) - Managed vector database for similarity search and RAG.
- [Weaviate](https://weaviate.io) - Open-source vector database with hybrid search and RAG support.
- [Qdrant](https://qdrant.tech) - High-performance vector search engine and database.
- [Chroma](https://www.trychroma.com) - Open-source embedding database for AI applications.
- [Milvus](https://milvus.io) - Scalable open-source vector database built for production.
- [pgvector](https://github.com/pgvector/pgvector) - Postgres extension for vector similarity search.

## Agent Frameworks

- [LangChain](https://www.langchain.com) - Framework for building context-aware reasoning applications with LLMs.
- [LangGraph](https://www.langchain.com/langgraph) - Low-level orchestration framework for stateful, multi-agent LLM applications.
- [OpenAI Agents SDK](https://github.com/openai/openai-agents-python) - OpenAI's official SDK for building agentic applications.
- [Pydantic AI](https://ai.pydantic.dev) - Type-safe agent framework built on Pydantic validation.
- [CrewAI](https://www.crewai.com) - Framework for orchestrating role-playing AI agents.
- [AutoGen](https://microsoft.github.io/autogen/) - Framework for building multi-agent conversations and workflows.
- [Semantic Kernel](https://github.com/microsoft/semantic-kernel) - Microsoft SDK for integrating LLMs into applications.
- [Haystack](https://github.com/deepset-ai/haystack) - Production-ready framework for building LLM applications and RAG pipelines.

## MCP & Agent Protocols

- [Model Context Protocol](https://modelcontextprotocol.io) - Open standard for connecting AI assistants to tools and data sources.
- [MCP Servers](https://github.com/modelcontextprotocol/servers) - Official reference servers implementing the Model Context Protocol.
- [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers) - Curated list of servers implementing the Model Context Protocol.
- [Google A2A](https://github.com/google/A2A) - Open protocol for communication and collaboration between AI agents.
- [AG-UI](https://github.com/ag-ui/ag-ui) - Open standard for interaction between frontend applications and AI agents.

## RAG & Data Ingestion

- [LlamaIndex](https://www.llamaindex.ai) - Data framework for connecting LLMs to external data sources.
- [Unstructured](https://github.com/Unstructured-IO/unstructured) - Open-source library for parsing and cleaning unstructured documents.
- [Chonkie](https://github.com/feyninc/chonkie) - Lightweight chunking library for building fast RAG pipelines.
- [Crawl4AI](https://github.com/unclecode/crawl4ai) - Open-source, LLM-friendly web crawler and scraper.
- [Firecrawl](https://github.com/firecrawl/firecrawl) - API for turning websites into LLM-ready markdown data.
- [Docling](https://github.com/docling-project/docling) - Document parsing toolkit that converts PDFs and office docs to structured formats.

## Evaluation & Observability

- [Langfuse](https://github.com/langfuse/langfuse) - Open-source LLM engineering platform for tracing, evals, and prompt management.
- [Braintrust](https://www.braintrust.dev) - AI platform for evals, tracing, and prompt management.
- [Ragas](https://github.com/explodinggradients/ragas) - Open-source framework for evaluating RAG pipelines.
- [Promptfoo](https://github.com/promptfoo/promptfoo) - Open-source tool for red-teaming and evaluating LLM applications.
- [Arize Phoenix](https://github.com/Arize-ai/phoenix) - Open-source AI observability and evaluation platform.
- [Weave](https://github.com/wandb/weave) - Weights & Biases toolkit for tracing and evaluating AI applications.

## AI Search & Research

- [Perplexity](https://www.perplexity.ai) - AI-powered search engine that returns cited, conversational answers.
- [Amicited](https://www.amicited.com) - AI research assistant for deep literature review and synthesis.
- [Astiva](https://astiva.ai) - AI-driven knowledge and research platform.
- [Exa AI](https://exa.ai) - AI-powered search and knowledge retrieval for developers and researchers.
- [Tavily](https://tavily.com) - Search API purpose-built for LLM agents and RAG.

## Coding Agents & Assistants

- [Cursor](https://www.cursor.com) - AI-first code editor built for pair-programming with an LLM.
- [GitHub Copilot](https://github.com/features/copilot) - AI pair programmer that suggests code completions and entire functions.
- [OpenSEO](https://openseo.dev) - AI agent framework for SEO automation and analysis.
- [Manus](https://manus.im) - General-purpose AI agent platform for task automation.
- [ZipTie.dev](https://ziptie.dev) - Platform for connecting and automating AI workflows.
- [Genspark](https://genspark.ai) - AI agent platform for building and deploying intelligent assistants.
- [Pluno](https://pluno.ai) - AI support agent that learns from resolved tickets to handle complex B2B support cases in Zendesk.
- [Eva Agent](https://www.goeva.ai/en/product) - AI agent platform with a built-in CRM for business workflows.
- [BrowserOS](https://www.browseros.com) - Open-source AI-native browser that runs agents in the browser.
- [Apso](https://apso.ai) - Agent-driven backend generation: a schema produces a production-ready API with auth, migrations, and deployment.
- [Devin](https://devin.ai) - Autonomous AI software engineer that plans and executes coding tasks.
- [Windsurf](https://windsurf.com) - Agentic AI code editor with a flow-based development model.
- [Cline](https://github.com/cline/cline) - Open-source AI coding assistant that edits code autonomously in your editor.
- [Aider](https://github.com/Aider-AI/aider) - AI pair programming in the terminal with git integration.
- [OpenHands](https://github.com/All-Hands-AI/OpenHands) - Open-source platform for autonomous AI software development agents.
